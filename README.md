# PDF-Merger-Tool
The PDF Merger Tool is a Python-based application used to combine multiple PDF files into a single PDF document. The project is developed using the PyPDF2 library, which provides functionalities for reading, merging, and manipulating PDF files.

# PDF Merger Tool

## Project Overview

The PDF Merger Tool is a Python application that combines multiple PDF files into a single PDF document using the PyPDF2 library.

The tool is simple, fast, and useful for document management tasks.


# Features

- Merge multiple PDF files
- Lightweight and fast
- Easy to use
- Beginner-friendly Python project

# Technologies Used

- Python
- PyPDF2


# Installation

## Step 1

Install required library:

pip install PyPDF2


# Run Project

python pdf_merger.py


# Project Structure

PDF-Merger-Tool/
│
├── pdf_merger.py
├── file1.pdf
├── file2.pdf
├── file3.pdf
└── merged_output.pdf


# How It Works

1. Load PDF files
2. Append files into merger object
3. Save merged PDF
4. Generate final output file
